# SmartPickHub Publishing Automation — Bootstrap

Branch: `automation/bootstrap-20261119`
Base: current `main` at branch creation
Production host: `https://smartpickhub.pages.dev/`

## Implemented in this branch

- Explicit per-guide `publicationStatus` gate; all existing 25 guides remain `draft`.
- Pinterest RSS 2.0 feed emits only guides with BOTH `publicationStatus: "published"` and `editorialStatus: "Approved for publication"`.
- Each eligible RSS item includes its canonical guide URL, original generated 1000×1500 PNG in both `enclosure` and `media:content`, title, description and category.
- Existing original cover generator remains the source of Pinterest artwork; no third-party or unlicensed product photography is used.
- Pinterest verification remains optional through build environment variable `PINTEREST_VERIFY_CODE`; the user must claim the exact production site in Pinterest.
- `dist/social-snippets.json` is generated after Astro build for eligible guides only. It contains X copy under 260 characters and short Medium/Substack Markdown with canonical source URL.
- `dist/deployment.json` records the deployed Git commit and branch. Cloudflare Pages provides `CF_PAGES_COMMIT_SHA` and `CF_PAGES_BRANCH` during build.
- `robots.txt` is generated by Astro: production `smartpickhub.pages.dev` is crawlable and declares the sitemap; all preview/non-production builds return `Disallow: /`. Shared page layout also outputs `noindex,nofollow` for preview builds.
- Distribution validation checks RSS 2.0, publication-gate parity, same-host URLs, 1000×1500 PNG dimensions, social bundle parity, canonical links and X character limits.
- IndexNow automation is chained after successful GitHub build-check on `main`; it waits for Cloudflare to serve the exact commit marker, then checks live robots, homepage robots meta, key file and sitemap URLs before notifying IndexNow. Manual dispatch is restricted to `main`.

## Important platform facts

- Pinterest RSS auto-publishing requires a Pinterest Business account and claimed website. Pinterest accepts RSS 2.x / RSS 1.x, not Atom. It reads item title/description and images from `image`, `enclosure` and `media:content`; every item link must be under the claimed website. Pinterest states new Pins may appear within 24 hours, oldest items first, with a maximum 200 Pins/day. See [Pinterest official instructions](https://help.pinterest.com/en/business/article/auto-publish-pins-from-your-rss-feed).
- IndexNow notifies participating search engines (including Bing and other current participants); it does NOT notify Google and does not guarantee crawling/indexing. Google remains managed through Search Console and sitemap submission. IndexNow is not represented as a direct ChatGPT Search submission.
- No WordPress dependency, paid scheduler, Pinterest API credential, Buffer or Zapier integration is introduced.
- No change is made to the live `main` branch or Cloudflare production settings in this bootstrap branch.
